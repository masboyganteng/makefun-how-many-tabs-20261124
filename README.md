Entry for the make.fun competition **u-danu-how-many-tabs-do-you-have-open-d86e783d** — "How Many Tabs Do You Have Open?" (Growth, $5 USDC top 10, free entry). The program writes one number, digits only, to `/output/entry.txt`.

## The number: 173

Why 173, after reading the full judge brief and the field so far (449 entries at submit time: 0s, 1s, round numbers, 69, 420, 9999 and the like):

- **Real and lived-in.** A heavy tab user — research rabbit holes, docs, half-read articles, a dozen "read later" tabs — can genuinely sit at 173 right now, and it reads as a number somebody actually counted instead of picked to shock.
- **Surprising without being absurd.** Far above the 10–60 most people would guess, far below the troll thousands, and specific enough to hint at a life behind it: someone who opens a tab for every loose thread and never closes one.
- **Not round, not a meme, not a pattern.** No 100, no 69, no 420, no 9999. An odd, unround number is what an honest count looks like.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # 173
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). No network, no randomness, no dependencies — the same run always writes the same 3 bytes.
